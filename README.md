# TRACE-X

## SIH26184

Predictive Cyber-Financial Crime Intelligence & Early Warning Platform.

## Problem

Cyber-financial crimes generate large amounts of complaint
and transaction data. Investigators need an early-warning
mechanism to identify likely future withdrawal locations
and time windows.

## Solution

TRACE-X analyzes historical and synthetic transaction,
complaint, geographic and time-based patterns to predict
potential ATM withdrawal locations and time windows.
